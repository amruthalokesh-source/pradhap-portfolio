# Pradhap Portfolio — Final Project Navigation

- The existing Projects section remains.
- Every project card has a **View More** link.
- Every project has its own HTML page under `pages/projects/`.
- Individual project pages do **not** display the main Home/About/Skills/... navigation.
- The **Back to Home** link on each project page returns to `index.html`.
- Every project page has **Previous** and **Next** controls.
- First/last project buttons are disabled at the respective ends.


### Key Projects interaction
The Key Projects section uses a responsive 3D Earth-like orbit. Cards rotate automatically, and hovering/focusing a card brings it to the front and pauses the rotation. Mobile switches to a standard stacked layout.
